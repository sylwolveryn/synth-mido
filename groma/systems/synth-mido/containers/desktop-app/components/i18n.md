`t(key, **values)` returns the text of a key in the active language, filling `{name}` placeholders; a missing key falls back to Hungarian, then to the key itself. Each language is one flat JSON file in `synth_mido/lang/` (hu reference, en, fr, ja, de, sv, fi, es, tlh) with exactly the reference keys, so the texts could later move into a database. Switching reloads the whole language. Core modules use it too (record validation errors, doubling and skin labels).
